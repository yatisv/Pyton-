Основы Python

Ввод, вывод, переменные и арифметика

1. Ввод данных (input)

Чтобы программа могла общаться с пользователем, нужно научить её слушать. В Python для этого используется функция input().

Как это работает:

Когда программа доходит до строчки с input(), она останавливается и ждет, пока пользователь что-нибудь напечатает и нажмет Enter.

# Простое приветствие
name = input("Как вас зовут? ")
print("Привет, " + name + "!")
Важно: Функция input() всегда возвращает строку (тип данных str), даже если вы ввели число.

Ввод чисел

Если вам нужно ввести число для математических вычислений, строку нужно преобразовать в число.

# Преобразование в целое число
age_str = input("Сколько вам лет? ")
age = int(age_str) # Или сразу: int(input(...))

# Преобразование в дробное число
price = float(input("Введите цену: "))

2. Вывод данных (print)

Чтобы программа показала результат, используется функция print(). Она выводит информацию на экран.

Способы вывода:

1. Вывод текста (строки):

print("Hello, World!")
print('Можно использовать одинарные кавычки')

2. Вывод нескольких значений (через запятую):

Запятая автоматически добавляет пробел между элементами.

name = "Анна"
age = 17
print("Имя:", name, "Возраст:", age)

3. F-строки (форматированные строки):

Самый удобный способ вывода. Перед кавычками ставится буква f, а переменные берутся в фигурные скобки {}.

city = "Москва"
print(f"Я живу в городе {city}")

3. Переменные и типы данных

Переменная — это именованная ячейка в памяти компьютера, где хранятся данные.

Основные типы данных:

  • int — целые числа (например: 5, -12, 1000).
  • float — вещественные (дробные) числа (например: 3.14, -0.5, 2.0).
  • str — строки, текст (например: "Привет", "123").
  • bool — логический тип (True или False).
a = 10        # int
b = 2.5       # float
c = "Школа"   # str
d = True      # bool

# Узнать тип переменной можно функцией type()
print(type(a)) # Выведет: <class 'int'>

4. Арифметические операции

Python умеет выполнять все стандартные математические операции.

Знак Операция Пример Результат
+ Сложение 5 + 3 8
- Вычитание 10 - 4 6
* Умножение 3 * 4 12
/ Деление (обычное) 7 / 2 3.5 (всегда float!)
// Целочисленное деление 7 // 2 3 (отбрасывает остаток)
% Остаток от деления 7 % 2 1 (то, что осталось)
** Возведение в степень 2 ** 3 8
Приоритет операций: Сначала выполняются действия в скобках, затем возведение в степень, затем умножение/деление, и в конце сложение/вычитание.
