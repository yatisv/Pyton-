Условный оператор

Учим программу принимать решения

1. Зачем нужны условия?

До этого момента все наши программы выполнялись линейно — сверху вниз, строчка за строчкой. Но в жизни мы часто делаем выбор: "Если идет дождь, беру зонт, иначе иду без зонта".

В программировании для этого используется условный оператор (if). Он позволяет программе выполнять разные блоки кода в зависимости от выполнения условия.

Начало программы
↓
Условие?
Да (True)
↓
Действие 1
Нет (False)
↓
Действие 2

2. Оператор if (Если)

Самый простой вариант ветвления. Код внутри блока if выполняется, только если условие истинно.

Синтаксис:

if условие:
    # блок кода (обязательно с отступом!)
    команда_1
    команда_2
# Код после блока (без отступа)
Правило отступов: Python использует отступы (обычно 4 пробела или 1 Tab), чтобы понять, какие строки относятся к условию. Если отступа нет — команда выполнится в любом случае!

Пример:

age = int(input("Введите возраст: "))

if age >= 18:
    print("Вы взрослый!")

print("Проверка завершена") # Эта строка выполнится всегда

3. Оператор else (Иначе)

Используется вместе с if. Блок else выполняется, если условие в if оказалось ложным.

Синтаксис:

if условие:
    # Делаем что-то, если условие ВЕРНО
else:
    # Делаем что-то другое, если условие НЕВЕРНО

Пример: Проверка пароля

password = input("Введите пароль: ")

if password == "12345":
    print("Доступ разрешен")
else:
    print("Неверный пароль! Доступ запрещен.")

4. Оператор elif (Иначе если)

Если нужно проверить несколько условий подряд, используется elif. Это сокращение от else if.

Программа проверяет условия сверху вниз. Как только находит верное, она выполняет его блок и останавливает проверку.

Пример: Оценка по баллам

score = int(input("Введите балл (0-100): "))

if score >= 90:
    print("Оценка: Отлично (5)")
elif score >= 70:
    print("Оценка: Хорошо (4)")
elif score >= 50:
    print("Оценка: Удовлетворительно (3)")
else:
    print("Оценка: Неудовлетворительно (2)")
Важно: В этом примере, если пользователь введет 95, сработает первое условие, а остальные будут пропущены.

5. Операторы сравнения

В условиях мы сравниваем значения. Результат сравнения — это логическое значение True (Истина) или False (Ложь).

Оператор Значение Пример Результат
== Равно (сравнение!) 5 == 5 True
!= Не равно 5 != 3 True
> Больше 10 > 5 True
< Меньше 5 < 3 False
>= Больше или равно 5 >= 5 True
<= Меньше или равно 4 <= 3 False
Частая ошибка: Не путайте оператор присваивания = (a = 5) и оператор сравнения == (if a == 5). В условиях всегда используйте двойное равно!

6. Логические операторы

Иногда нужно проверить несколько условий сразу.

  • and — логическое И. Возвращает True, если оба условия верны.
  • or — логическое ИЛИ. Возвращает True, если хотя бы одно условие верно.
  • not — логическое НЕ. Меняет значение на противоположное (True на False).

Пример с and:

Проверка доступа: возраст от 18 И есть паспорт.

age = int(input("Возраст: "))
has_passport = input("Есть паспорт? (да/нет): ")

if age >= 18 and has_passport == "да":
    print("Доступ разрешен")
else:
    print("Доступ запрещен")

Пример с or:

Выходной: Суббота ИЛИ Воскресенье.

day = input("День недели: ")

if day == "Суббота" or day == "Воскресенье":
    print("Ура, выходной!")
else:
    print("Рабочий день")

7. Вложенные условия

Условия можно вкладывать друг в друга, как матрешки. Это используется для сложных проверок.

age = int(input("Возраст: "))

if age >= 18:
    print("Вам 18 или больше")
    
    # Вложенное условие
    if age >= 60:
        print("Вы пенсионер")
    else:
        print("Вы еще работаете")
        
else:
    print("Вы несовершеннолетний")
Совет: Старайтесь не делать больше 2-3 уровней вложенности, иначе код становится трудным для чтения. Лучше использовать elif.
