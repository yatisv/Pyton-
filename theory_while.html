Цикл WHILE

Цикл с условием

1. Что такое цикл while?

Цикл while (цикл "пока") выполняет блок кода до тех пор, пока истинно проверяемое условие. В отличие от цикла for, он не требует знания точного количества итераций заранее.

Определение: while — это цикл с предусловием. Это значит, что условие проверяется перед каждым выполнением тела цикла.

Когда использовать?

  • Когда количество повторений заранее неизвестно.
  • Когда мы ждем наступления определенного события (например, ввода числа 0).
  • При работе с интерактивными программами.

2. Синтаксис цикла while

Общая структура:

while условие:
    # Тело цикла
    команда_1
    команда_2

Основные элементы:

  • while — ключевое слово.
  • Условие — логическое выражение (True/False).
  • Двоеточие (:) — обязательный символ.
  • Тело цикла — команды с отступом, которые повторяются.

3. Логика работы (Пошагово)

  1. Python проверяет Условие.
  2. Если условие истинно (True), выполняется тело цикла.
  3. После выполнения тела цикла Python возвращается к проверке условия (шаг 1).
  4. Если условие ложно (False), цикл завершается, и программа идет дальше.

Пример: Обратный отсчет

i = 5
while i > 0:
    print(i)
    i = i - 1 # Важно: изменяем переменную!
print("Пуск!")

4. Типичная задача: Ввод до стоп-сигнала

Частая задача: программа должна читать числа, пока пользователь не введет 0.

total = 0
number = int(input("Введите число: "))

while number != 0:
    total += number
    number = int(input("Введите число: "))

print("Сумма:", total)
Схема работы: 1. Считываем первое число до цикла.
2. Пока число не равно 0, добавляем его к сумме и считываем следующее.
3. Как только введен 0, условие number != 0 становится False, цикл останавливается.

5. Бесконечный цикл

Если условие в while никогда не станет ложным, цикл будет работать бесконечно. Это часто является ошибкой.

Пример ошибки: 
x = 5
while x > 0:
    print(x)
    # Забыли написать x = x - 1
# Этот цикл будет печатать 5 бесконечно!

Как остановить?

В среде разработки нажмите Ctrl+C или кнопку "Stop", чтобы принудительно прервать программу.

Полезный бесконечный цикл

Иногда бесконечный цикл создают намеренно (например, для игры или меню), а выход делают через break.

while True:
    answer = input("Введите 'exit' для выхода: ")
    if answer == "exit":
        break
    print("Вы ввели:", answer)

6. Сравнение: FOR vs WHILE

Характеристика Цикл FOR Цикл WHILE
Когда используем Когда точно знаем количество повторений (или перебираем последовательность). Когда количество повторений неизвестно заранее, зависит от условия.
Пример Вывести числа от 1 до 100. Читать числа, пока не встретится 0.
Опасность Меньше риск "зацикливания". Высокий риск бесконечного цикла, если забыть изменить переменную.

7. Типичные ошибки

1. Забыли изменить переменную условия

Самая частая ошибка. Переменная, участвующая в условии, должна меняться внутри цикла.

2. Условие сразу ложно

Если условие ложно с самого начала, тело цикла не выполнится ни разу.

x = 0
while x > 0:
    print("Никогда не напечатается")
3. Путаница с операторами

Использование = (присваивание) вместо == (сравнение) в условии вызовет ошибку SyntaxError.
