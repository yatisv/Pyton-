Строки (Strings)

Работа с текстовой информацией

1. Что такое строка?

Строка (str) — это тип данных, представляющий собой последовательность символов. Строки используются для хранения текстовой информации.

Определение: Строка — это упорядоченная неизменяемая последовательность символов, заключенная в кавычки.

Создание строк

Строки в Python заключаются в одинарные (' ') или двойные (" ") кавычки. Разницы нет.

s1 = "Привет, мир!"
s2 = 'Python'
s3 = "" # Пустая строка

2. Операции со строками

Конкатенация (склеивание)

Оператор + объединяет две строки в одну.

first = "Hello"
last = "World"
full = first + " " + last
print(full) # Вывод: Hello World

Дублирование (умножение)

Оператор * повторяет строку указанное количество раз.

print("=" * 10)
# Вывод: ==========

Длина строки

Функция len() возвращает количество символов в строке.

s = "Python"
print(len(s)) # Вывод: 6

3. Индексация символов

К каждому символу строки можно обратиться по его номеру (индексу). Индексация начинается с 0.

Также можно использовать отрицательные индексы для отсчета с конца (-1 — последний символ).

s = "PYTHON"
# Индексы:  0 1 2 3 4 5
# Обратные:-6-5-4-3-2-1

print(s[0])  # P (первый символ)
print(s[5])  # N (последний по порядку)
print(s[-1]) # N (последний с конца)
Важно: Попытка обратиться к несуществующему индексу вызовет ошибку IndexError.

4. Срезы (Slices)

Срез позволяет получить часть строки (подстроку).

Синтаксис среза:

s[начало:конец:шаг]
  • начало — индекс, с которого начинаем (включительно).
  • конец — индекс, на котором заканчиваем (не включительно!).
  • шаг — через сколько символов брать.

Примеры:

s = "PROGRAMMING"

print(s[0:3])   # PRO (символы с 0 по 2)
print(s[3:7])   # GRAM
print(s[:5])    # PROGR (от начала до 4)
print(s[5:])    # AMMING (с 5 до конца)
print(s[-3:])   # ING (последние 3 символа)

# Шаг
print(s[::2])   # PORMIG (каждый второй символ)
print(s[::-1])  # GNIMMARGORP (строка наоборот)

5. Неизменяемость строк

В Python строки являются неизменяемыми (immutable). Это значит, что после создания строки вы не можете изменить в ней отдельный символ.

Ошибка: 
s = "Кот"
s[0] = "Б" # TypeError: 'str' object does not support item assignment

Как тогда изменить строку?

Нужно создать новую строку на основе старой.

s = "Кот"
s = "Б" + s[1:] # Создаем новую строку: "Б" + "от"
print(s) # Вывод: Бот

6. Основные методы строк

Методы — это функции, которые "прикреплены" к объекту и вызываются через точку.

Метод Описание Пример
.upper() Все буквы в верхний регистр (ПРОПИСНЫЕ). "hi".upper() → "HI"
.lower() Все буквы в нижний регистр (строчные). "HI".lower() → "hi"
.replace(a, b) Заменяет все вхождения подстроки a на b. "ball".replace("l", "t") → "batt"
.strip() Удаляет пробелы в начале и конце строки. " hi ".strip() → "hi"
.split(sep) Разбивает строку на список по разделителю. "a b c".split() → ['a', 'b', 'c']
.find(s) Возвращает индекс первого вхождения s (или -1). "apple".find("p") → 1

7. Ввод и форматирование

Функция input() всегда возвращает строку!

Даже если вы введете число, Python воспримет его как текст.

x = input("Введите число: ") # Ввели 5
# x сейчас это строка "5"
x = int(x) # Преобразовали в число 5

F-строки (форматирование)

Удобный способ вставить переменные в текст. Буква f перед кавычками.

name = "Анна"
age = 17
print(f"Меня зовут {name}, мне {age} лет.")
