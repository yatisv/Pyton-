Цикл FOR

Учим программу повторять действия

1. Что такое цикл?

Цикл — это конструкция, которая позволяет выполнять одну и ту же последовательность команд многократно.

Определение: Цикл for в Python часто называют "циклом со счетчиком" или "циклом перебора". Он используется, когда количество повторений заранее известно или когда нужно перебрать все элементы последовательности.

Пример задачи:

Вместо написания 5 строк print("Привет"), мы пишем одну конструкцию цикла.

2. Синтаксис цикла for

Общая структура:

for переменная in последовательность:
    # Тело цикла (действия)
    команда_1
    команда_2

Основные элементы:

  • for — ключевое слово, открывающее цикл.
  • переменная — счетчик (например, i), который принимает текущее значение.
  • in — связывает переменную с последовательностью.
  • Двоеточие (:) — обязательный знак конца заголовка.
  • Отступ — все команды внутри цикла сдвигаются вправо (обычно 4 пробела).

3. Функция range() — генератор чисел

Функция range() используется для генерации последовательности целых чисел. Это основной инструмент для работы цикла for заданное количество раз.

Вариант 1: range(stop) — от 0 до N-1

Генерирует числа от 0 до указанного числа не включительно.

for i in range(5):
    print(i)
# Вывод: 0, 1, 2, 3, 4
# Обратите внимание: цифры 5 НЕТ в выводе!
Правило левой границы: Python начинает отсчет с 0. Поэтому range(5) дает 5 чисел: 0, 1, 2, 3, 4.

Вариант 2: range(start, stop) — от A до B-1

Генерирует числа от начального до конечного (не включая конечное).

for i in range(1, 6):
    print(i)
# Вывод: 1, 2, 3, 4, 5

Вариант 3: range(start, stop, step) — с шагом

Третий параметр задает шаг изменения счетчика.

# Вывод четных чисел от 0 до 10
for i in range(0, 11, 2):
    print(i)
# Вывод: 0, 2, 4, 6, 8, 10

Обратный отсчет (отрицательный шаг)

for i in range(5, 0, -1):
    print(i)
# Вывод: 5, 4, 3, 2, 1

4. Алгоритм накопления суммы

Циклы часто используют для подсчета суммы чисел. Для этого перед циклом создают специальную переменную — аккумулятор (накопитель).

Пример: Сумма чисел от 1 до N

n = int(input("Введите число N: "))
total_sum = 0 # Инициализация аккумулятора

for i in range(1, n + 1):
    total_sum = total_sum + i # Добавляем i к сумме

print("Сумма:", total_sum)
Как это работает: На каждом шаге цикла переменная total_sum увеличивается на значение i. В конце цикла она содержит итоговую сумму.

5. Управление циклом: break и continue

Оператор break (Прерывание)

break — команда, которая мгновенно останавливает выполнение цикла. Программа переходит к коду после цикла.

for i in range(100):
    if i == 5:
        print("Нашли 5! Стоп.")
        break
    print(i)

Оператор continue (Продолжение)

continue — команда, которая пропускает оставшиеся команды в текущем шаге цикла и переходит сразу к следующему шагу.

# Выводим числа от 0 до 5, пропуская 3
for i in range(6):
    if i == 3:
        continue
    print(i)
# Вывод: 0, 1, 2, 4, 5

6. Типичные ошибки

1. Забыли двоеточие 
for i in range(5) # SyntaxError!
    print(i)
2. Ошибка в границах range()

Путают, что верхняя граница не включается. Чтобы перебрать числа от 1 до 10, нужно писать range(1, 11), а не range(1, 10).

3. Изменение переменной цикла внутри

В Python переменная цикла (например, i) автоматически обновляется на каждом шаге. Если вы попытаетесь изменить её вручную внутри цикла (например, i = i + 5), это не повлияет на количество итераций.
